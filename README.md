# Inayati / عنايتي

Download the Android APK and checksum from the [reviewer release](https://github.com/bakkey/inayati-review/releases/tag/v0.5.0-synthetic). Open Inayati and choose **Start my care journey**. No account is needed for the local synthetic demonstration.

The competition prototype demonstrates care after screening with fictional clinic records. Authorised Abu Dhabi EMR and e-prescription integration is the intended pathway.
